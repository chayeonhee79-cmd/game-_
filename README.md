# 거제 행복마블

종합사회복지관에서 출발해 거제 명소를 여행하고 돌아오는 1~4인 웹 보드게임입니다. HTML, CSS, JavaScript로 제작했으며 Vercel에 배포할 수 있습니다. 관광지 실사진과 직접 작성한 SVG, 시스템 이모지를 사용합니다. 사진 출처와 이용 조건은 `PHOTO-CREDITS.md`에 있습니다. Google Fonts가 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 실행

Node.js 설치 후 프로젝트 폴더에서 실행합니다.

```sh
npm run dev
```

브라우저에서 http://localhost:3000 을 여세요. HTML을 더블클릭하는 file:// 방식은 JavaScript 모듈을 지원하지 않습니다. 의존성 패키지 설치는 필요하지 않습니다.

```sh
npm test
npm run build
```

## GitHub와 Vercel

1. 이 폴더의 소스 파일을 GitHub 새 저장소에 업로드합니다. `.gitignore` 등 숨김 파일도 포함해 주세요. `dist`는 업로드하지 않아도 됩니다.
2. Vercel에서 Add New → Project → GitHub 저장소를 선택합니다.
3. Framework Preset은 Other, Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. `vercel.json`에도 포함되어 있습니다.
4. Deploy를 누르면 공개 주소가 생성됩니다. 이후 GitHub 변경 사항을 푸시하면 다시 배포됩니다.

## Firebase 온라인 모드 설정

기존 코드가 없어 Firebase 연결을 새로 구성했습니다. 연결 전에는 로컬 모드가 동작하며 진행 상황이 브라우저에 자동 저장됩니다.

1. Firebase Console에서 프로젝트와 웹 앱을 생성합니다.
2. Authentication → Sign-in method에서 Anonymous(익명 로그인)를 활성화합니다.
3. Firestore Database를 생성합니다.
4. `firebase-config.js`에 웹 앱의 `apiKey`, `authDomain`, `projectId`, `appId`를 입력합니다. 웹 앱 설정은 공개 클라이언트 설정이며 서비스 계정 비밀키를 넣지 마세요.
5. Firestore → Rules에 `firestore.rules` 내용을 붙여 넣고 게시합니다. Firebase CLI가 있다면 `firebase deploy --only firestore:rules --project YOUR_PROJECT_ID`도 가능합니다.
6. Authentication → Settings → Authorized domains에 Vercel 도메인과 개발용 localhost를 등록합니다.
7. 온라인 방 만들기로 코드를 만들고 다른 기기에서 같은 코드를 입력합니다. 방장이 시작하면 플레이가 진행됩니다. 같은 브라우저의 탭은 익명 로그인 ID를 공유하므로 서로 다른 플레이어 테스트는 다른 브라우저/기기를 사용하세요.

`rooms/{6자리코드}` 문서에 플레이어 위치, 방문 관광지, 획득 관광지, 행복 포인트, 퀴즈 기록, 진행 상태, 최종 결과를 저장합니다. `onSnapshot`으로 공유 상태를 구독하고 트랜잭션으로 차례를 처리합니다. 실제 Firebase 프로젝트가 연결되어야 온라인 모드를 사용할 수 있습니다.

규칙은 회원·차례·방장·수정 필드를 제한하는 지인 간 게임용 기본 정책입니다. 점수 계산과 주사위는 클라이언트에서 수행하므로 경쟁 대회용 부정행위 방지에는 서버 권위 방식(Cloud Functions 등)이 추가로 필요합니다. 방 코드를 아는 익명 사용자는 방 내용을 조회할 수 있습니다. 계정 비밀정보를 게임 데이터에 기록하지 마세요. 자동 방 삭제 및 이탈 플레이어 건너뛰기는 포함되어 있지 않습니다.

Firebase 공식 참고: [실시간 구독](https://firebase.google.com/docs/firestore/query-data/listen), [트랜잭션](https://firebase.google.com/docs/firestore/manage-data/transactions), [익명 로그인](https://firebase.google.com/docs/auth/web/anonymous-auth).

## 게임 규칙

- 24칸 순서는 요청한 순서를 그대로 따릅니다. 첫 칸과 마지막 칸은 각각 복지관 출발·도착입니다.
- 주사위 1개로 이동하며, 24번 칸에 도착하거나 통과하면 거기에 멈춥니다. 순환하지 않습니다.
- 관광지 방문 +80점, 퀴즈 정답 +50점, 행복카드 +100점, 나눔카드 본인 +60점/아직 여행 중인 다른 친구 +30점, 휴식 +40점입니다.
- 퀴즈 후 명소 획득은 60점, 본인 명소 발전은 40점이며 최대 3단계입니다. 비용은 점수에서 차감됩니다. 한 번만 도는 여행에서 발전도 경험할 수 있도록 획득 직후 같은 방문에서 발전할 수 있습니다.
- 복지관 도착 보너스는 200점이며 한 번만 지급합니다. 도착한 플레이어는 차례에서 제외합니다.
- 모두 여행을 마친 후 행복 포인트 순으로 결과를 표시하며 동점은 공동 우승입니다. 획득 명소의 별도 종료 점수나 통행료는 없습니다.
- 여행 기록은 방문한 관광지만 나열합니다. 주사위로 지나친 칸은 방문으로 계산하지 않습니다.

## 파일

`game.js`는 순수 게임 규칙, `app.js`는 UI와 일러스트, `firebase.js`는 온라인 방 처리, `style.css`는 반응형 디자인입니다. `game.test.js`는 도착·보너스·차례·퀴즈·획득 핵심 동작을 검증합니다.

## 이번 수정

- 주사위 한 개에 1~6 숫자를 표시하고 나온 숫자만큼 말을 이동합니다.
- 여행 준비에서 1~4명을 선택하면 인원에 맞게 이름 입력칸이 표시됩니다. 이름을 입력하고 새 로컬 여행 시작을 누르면 적용됩니다.
- 관광지 17곳 중 16곳은 사용 권한을 확인한 실제 사진을 소스에 포함했습니다. 계룡산은 권한이 확인된 사진을 확보하지 못해 일러스트를 유지하고 사진 준비 중이라고 표시합니다.
- 장승포항은 1950년대 기록 사진이며, 거제시청 주변은 시청 주변 고현성 사진입니다.
- `assets/photos` 폴더와 `photos.js`, `PHOTO-CREDITS.md`를 함께 GitHub에 올려야 사진이 배포됩니다.

- 부르마블 형태의 바깥쪽 24칸을 따라 이동하며, 중앙에 실제 거제도 윤곽을 바탕으로 만든 관광 지도를 배치했습니다.
- 케이블카 사진은 거제시청 공공누리 제4유형 자료로, 비상업적 이용만 허용하며 사진 변경·크롭을 하지 않습니다. 상업적 배포 시 이 사진을 별도 허가 받은 이미지로 교체해야 합니다.

중앙 지도 윤곽: 통계청(KOSTAT) 2013 시군구 경계, southkorea-maps 제공(공유·변형 허용). 지도는 게임용으로 단순화했으며 관광지 표시는 개략적입니다. https://github.com/southkorea/southkorea-maps

중앙 지도는 KOSTAT 2013 상세 해안선 자료를 사용합니다. 24개 보드 번호와 명칭을 모두 표시하며 복지관 출발·도착은 옥포의 동일 지점입니다. 관광지 위치는 개략적인 안내용이며 카드·휴식은 실제 장소가 아닌 가상 지점입니다. 지도 크게 보기에서 지점을 누르면 상세 안내를 표시합니다.
